# Calculator of Knots and Links v0.1.2

> `v0.1.2` is prepared as a desktop usability hotfix release candidate.

## English

This release candidate focuses only on desktop workflow usability:

- split the invariant tab into **Braid setup / preview** and
  **Calculation / results** pages;
- make **Manual braid input** explicit in setup mode;
- keep a larger, resizable braid preview and resizable result layout;
- keep branch selection scrollable with separate branch details;
- keep Curated examples and Mathematics tabified on the right and closed by default.

No mathematical behavior changes are introduced in this hotfix. Braid
conventions, R/check-R usage, q conventions, normalization, and invariant outputs
are unchanged.

## 中文

本次发布候选仅包含桌面工作流可用性热修复：

- 将不变量标签页拆分为 **Braid setup / preview** 与
  **Calculation / results** 两页；
- 在设置模式中明确提供 **Manual braid input**；
- 保持更大的可调整辫子预览区，并保留结果区可调布局；
- 分支选择保持可滚动，并与分支详情分离显示；
- Curated examples 与 Mathematics 继续在右侧停靠区标签化显示，默认关闭。

该热修复不引入数学行为变化。辫子约定、R/check-R 用法、q 约定、归一化及
不变量输出均保持不变。
